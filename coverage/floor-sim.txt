# **NOT ON THIS FLOOR, AND WHERE THEY ARE REACHED** (the box, 2026-10-16;
# no simulator reached them at 1,000 seeds):
# - "tcp: a connection of our own is refused by the peer's reset": our own
#   server never answers a SYN with a reset (a closed port and a full table
#   both drop it: DEPARTS (bounded)), so only another stack refuses. The
#   native judge's fetch case "refused" reaches it, against Linux.
# - "arp: the cached peer's hardware address changes", "arp: the one entry
#   is replaced by another peer": no simulator speaks ARP; arp.zig's unit
#   tests reach both.
# - "tcp: a peer names a segment size under the least, and is sent the
#   least": tcp_sim's peers name no MSS under 536; tcp_test reaches it.
#   A rough peer that does would put it back here.
# - "tcp: a segment ahead finds the held pieces full, and is dropped":
#   five holes open at once; the pair sim's reordering (one path's jitter)
#   never makes more than four. tcp_test reaches it. A gap to close in the
#   pair sim, not a line to forget.
# - PLANT lines: only a planted build reaches them, by design.
